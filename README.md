# AUTOSAR HLD Assistant — Capstone Submission

Replace `UniversityName`, `StudentName`, `RegisterNo`, and `CSx` in this folder name with your details. This package contains the complete project source recovered from the original project folder, organized into the capstone submission sections.

## Included
- `Synopsis/`: project synopsis.
- `Input_Data/`: synthetic sample HLD and evaluation questions.
- `Code/`: Streamlit app, `src/`, `scripts/`, `tests/`, data copy, and requirements.
- `Model_Prompts_Config/`: safe example configuration; no real credentials.
- `Evaluation_Results/`: included test-results report.
- `Documentation/`: original project README and report outline.
- `Video/`: demo script and recording instructions.
- `Declarations/`: AI usage declaration and academic-integrity template.

The source `.venv`, `.tmp`, caches, and temporary build output are excluded. The final signed declarations, exported technical report PDF, and recorded demo video still need to be added before submission.
