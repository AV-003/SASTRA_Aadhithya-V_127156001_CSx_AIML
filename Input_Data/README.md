# Input Data

This project includes a synthetic Vehicle Lighting Controller HLD sample in `Input_Data/data/sample_documents/` and a sample evaluation-question list in `Input_Data/data/evaluation_questions.json`. The source code keeps its own copy under `Code/data/` so the app can load the demo document using its existing relative path.

The synthetic PDF is for demonstration only; it is not real AUTOSAR, OEM, supplier, or production documentation. The PDF generator is in `Code/scripts/create_sample_pdf.py`.
